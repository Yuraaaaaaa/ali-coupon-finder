Quick switch

Search

When AliExpress asks to replace the current coupon, accept it so totals can be compared.

Invalid codes are skipped for 3 days, expired and wrong-country codes for 7, already used codes for 30. Sold-out codes are always retried.

Waiting for sold-out codes

Apply each sold-out code as soon as it frees up, smaller ones too, so it’s saved to your account. The biggest one is put back on the order after each round. When off, only codes bigger than the applied one are waited for.

Each round tries all sold-out codes one after another, then waits this long before the next round.
